## What this is

WebTopup — an Indonesian PPOB / digital top-up platform. Laravel 12 + Inertia v2 + Vue 3 + Tailwind v4, MySQL 8 + Redis. Two surfaces: public storefront/checkout and a permission-gated `cms` admin. Integrations: Midtrans (payments), Digiflazz + API Games (suppliers), plus Voda / game-proxy services.

## Commands

- Dev loop: `composer run dev` (runs `artisan serve`, `queue:listen`, `pail`, and Vite together). `npm run dev` alone only starts Vite.
- Build assets (required before Inertia pages render in tests/manual checks): `npm run build`.
- Tests: `php artisan test --compact`; single file/filter: `php artisan test --compact tests/Feature/Foo.php` or `--filter=name`. `composer test` clears config first.
- PHP format: `vendor/bin/pint --dirty --format agent`. Frontend: `npm run format` (prettier, writes `resources/`) then `npm run lint` (eslint `--fix`). CI runs Pint + `npm run format` + `npm run lint` on `develop`/`main`.
- There is no `typecheck` npm script (`vue-tsc` is installed but unscripted).
- Docker: `./docker-run.sh setup|up|down|shell|artisan|composer|test|pint|logs|reset` (bash — use Git Bash/WSL on Windows). App at http://localhost.

## Backend conventions (follow these)

- **Routes are split**, not monolithic. `routes/web.php` requires `routes/web/{settings,cms,main}.php`; `routes/api.php` requires `routes/api/v1.php`, which **only** loads `routes/api/v1/callback.php` (Midtrans/Digiflazz webhooks). `routes/api/v1/{auth,role,user}.php` exist but are **not wired up** — require them in `v1.php` if you need them. Add routes to the matching file. The `routes/web/cms.php` group auto-applies prefix `cms`, name `cms.`, and middleware `auth,verified,role:superadmin|admin`; it further requires `routes/web/cms/{web,ppob,order,setting,management}.php`.
- **Request → Controller → Action → Model.** Controllers stay thin; write single-purpose Action classes per operation (`StoreXAction`, `UpdateXAction`, `DeleteXAction`, `HandleXCallbackAction`) exposing a `handle()` method. Actions live under `app/Actions/{Cms,Api,Main,Fortify}/...` mirroring `app/Http/Controllers/...`; Form Requests under `app/Http/Requests/...`. Copy an existing triad before inventing a new pattern.
- **Models are grouped by domain subnamespace**: `App\Models\PPOB\PPOBProduct`, `App\Models\Order\Order`, `App\Models\Menu\Menu`, `App\Models\Web\Faq`, `App\Models\Voucher\Voucher`. There is no flat `App\Models\Product`.
- **Authorization uses Spatie permissions named `{prefix}{FQCN}`** — controllers set `protected string $resource = Model::class;` then `Gate::authorize('view'.$this->resource)`. Prefixes: view/show/create/update/delete/restore/forceDelete/export/import/validate. `PermissionSeeder` auto-discovers every class in `app/Models`; **after adding a model run `php artisan db:seed --class=PermissionSeeder`** or the permission won't exist. Guard is `api` (`User::$guard_name`). Roles: `superadmin`, `admin`, `user`. Seeded logins (password `password`): superadmin@superadmin.com, admin@admin.com, user@user.com.
- **Index/list endpoints** use `App\Traits\WithGetFilterData::getDataWithFilter()` (pagination via `fastPaginate`) and pass `order/orderBy/paginate/search/searchBySpecific` back to the Vue page.
- **Global helpers** in `app/helpers.php` (autoloaded): `getSetting($key)` (cached `Cache::flexible('global:settings', [60,120])`), `numberToCurrency`, `currencyToNumber`, `transactionUrl($order)`, `transactionUpdateUrl($order)` (both produce signed URLs using named routes `transaction.show` / `transaction.update`). Use `getSetting()` rather than querying `Setting`.
- Scheduled job `App\Jobs\ExpirePayments` runs hourly (`routes/console.php`). Integration configs: `config/{digiflazz,midtrans,game,gamepro,voda}.php`; env keys in `.env.example` / `.env.docker`.

## Frontend conventions

- Inertia pages live in `resources/js/pages`; names are lowercase/kebab and mirror the backend path (`resources/js/pages/cms/management/menu/Index.vue` → `inertia('cms/management/menu/Index')`).
- **Wayfinder-generated TS route helpers** live in `resources/js/actions` and `resources/js/routes` (both gitignored) and are emitted by the Vite plugin during `npm run dev`/`build` — never hand-edit them. Import from `@/actions/App/Http/Controllers/...` and `@/routes/...`. Re-run Vite after route changes.
- Alias `@/*` → `resources/js/*`. UI is shadcn-style on `reka-ui` under `resources/js/components/ui`; style with Tailwind v4 + `cn`/`cva`/`clsx`. Prettier enforces 80 cols, 4-space tabs, and sorts imports + Tailwind classes.
- Inertia v2 + `@inertiaui/modal-vue` (modal/slideover config in `resources/js/app.ts`), plus `@tanstack/vue-query`. SSR is enabled in `config/inertia.php`; `composer run dev:ssr` runs the SSR server.

## Tests

- Pest 4. `tests/Feature` auto-applies `RefreshDatabase` (`tests/Pest.php`); `tests/Unit` does not — DB-touching Unit tests opt in via `uses(TestCase::class, RefreshDatabase::class)` (see `tests/Unit/Actions/...`). `tests/Pest.php` also defines a `makeTestOrder()` helper. The suite runs on SQLite `:memory:` with array/sync drivers (`phpunit.xml`) — no MySQL/Redis required.
- The test workflow is disabled (`.github/workflows/tests.yml.disable`); only lint CI is active.

=== laravel/v12 rules ===

# Laravel 12

- CRITICAL: ALWAYS use `search-docs` tool for version-specific Laravel documentation and updated code examples.
- Since Laravel 11, Laravel has a new streamlined file structure which this project uses.

## Laravel 12 Structure

- In Laravel 12, middleware are no longer registered in `app/Http/Kernel.php`.
- Middleware are configured declaratively in `bootstrap/app.php` using `Application::configure()->withMiddleware()`.
- `bootstrap/app.php` is the file to register middleware, exceptions, and routing files.
- `bootstrap/providers.php` contains application specific service providers.
- The `app/Console/Kernel.php` file no longer exists; use `bootstrap/app.php` or `routes/console.php` for console configuration.
- Console commands in `app/Console/Commands/` are automatically available and do not require manual registration.

## Database

- When modifying a column, the migration must include all of the attributes that were previously defined on the column. Otherwise, they will be dropped and lost.
- Laravel 12 allows limiting eagerly loaded records natively, without external packages: `$query->latest()->limit(10);`.

### Models

- Casts can and likely should be set in a `casts()` method on a model rather than the `$casts` property. Follow existing conventions from other models.
